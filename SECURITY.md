# Security Policy

## Supported versions

Only the latest published release of `@volo-uti/volo-web-utils`, and the default branch, receive security fixes. If you run an older version, please upgrade before reporting.

## Reporting a vulnerability

Please do not open a public issue, discussion or pull request for a security problem.

Report it privately through GitHub:

1. Open this repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Fill in the form and submit it.

Only the maintainers can see the report. If you cannot use the form, open a public issue that says only that you need a private channel, without any details, and a maintainer will arrange one.

## What to include

- The package and version, or the commit, that is affected.
- A description of the problem and its impact.
- Steps or a minimal example that reproduces it.
- Any fix or mitigation you already know of.

## What to expect

- We acknowledge your report within 7 days.
- We assess it, keep you informed of progress, and tell you if we decide it is not a vulnerability.
- When a fix is ready we publish a new release and a security advisory. We credit you in the advisory unless you prefer to stay anonymous.

Please keep the details private until the advisory is published, and give us a reasonable time to fix the problem before you disclose it.
